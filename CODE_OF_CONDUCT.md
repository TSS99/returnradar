# Code of conduct

Be respectful, constructive and welcoming. Discuss ideas and behavior without
personal attacks. Harassment, threats, discriminatory language, and publishing
someone's private information are unacceptable.

Use synthetic examples; receipts can contain sensitive data. Respect other
contributors' boundaries and time. Maintainers may edit/remove abusive content,
close disruptive discussions, and restrict participation proportionate to the
conduct. Report concerns through a private maintainer channel where available;
if no private channel is listed, request one without sharing sensitive details.
