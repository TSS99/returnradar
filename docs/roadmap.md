# Roadmap

These are proposals, not shipped features or promises. Core local tracking
must stay usable without paid model/API credits.

| Version | Direction | Gate |
| --- | --- | --- |
| 0.2 | Optional local OCR, Gmail purchase-email connector, better notification channels, merchant policy adapters | Explicit credentials/consent, no automatic charges, evidence-preserving extraction |
| 0.3 | Authentication, secure multi-user storage, optional cloud sync, hosted mobile-friendly UI | Identity, authorization, tenant isolation, transport/storage/privacy review |
| 0.4 | Richer return/refund workflow history, optional merchant integrations, useful analytics | User-reported vs merchant-confirmed events remain distinct |
| 1.0 | Reliable hosted MCP, OAuth, complete directory submission package and platform review | Real secured HTTPS service, operational tests, accepted submission |

Immediate usability improvements to consider: multi-item receipt splitting,
attached-document replacement, more date formats without guessing, configurable
merchant cutoff hour/inclusive counting, filtered exports and a safe backup restore UI.
